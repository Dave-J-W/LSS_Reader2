The text files do not change. Each sidecar holds, point for point, the counting-only error, which scan(s) each point came from, and the covariance of the scans' scale factors: a factor's error is shared by every point of its scan and of every later scan, so the errors are correlated, and a fit that treats them as independent is overconfident (synthetic film fits: parameter pull SDs up to 4 instead of 1).
