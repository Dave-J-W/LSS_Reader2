| Main window | Reflectivity | refCovarianceCheckBox | QCheckBox | + covariance | Off by default (the owner decides, TODO area B2). The text files do not change. Each sidecar holds, point for point, the counting-only error, which scan(s) each point came from, and the covariance of the scans' scale factors: a factor's error is shared by every point of its scan and of every later scan, so the errors are correlated, and a fit that treats them as independent is overconfident (synthetic film fits: parameter pull SDs up to 4 instead of 1). The factors are those of the patch (joint or legacy, Preferences); their errors are recomputed from counting errors, inflated when the overlap scatters. Only for a Ref Patch reduction; nothing is written if the patch cannot be replayed exactly (a message says why). |
