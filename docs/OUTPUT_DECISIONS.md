# Decisions that change the numbers in output files

One central register (owner, 2026-11-19): every choice, large or small,
that changes a number the reader writes or plots, with its rationale and
**how the rationale is proven**. For reviewers, for the figure agent
(`COMPARISONS.md`), and for the manual writer (`MANUAL_NOTES.md`).

Evidence: **O** the owner said so (date); **T** a test pins it; **M**
measured on data (entry in `physics_notes.md`); **L** taken from
literature or a hand-off (cited); **A** an assumption of this project, not
yet confirmed. A row with only **A** is a candidate question for the owner.

Rule (AGENTS.md rule 11): a commit that changes an output number adds or
updates a row here in the same commit, with before and after values.

- SpecPlot flat-scan threshold `FLAT_P` = 0.05 (2026-11-23): a feature
  needs only weak (5 %) evidence against the background alone to be
  fitted. 0.01 would skip 99 % of flat scans but more weak peaks.
- Sample-height scans (2026-11-23): signal/background at least 2 (the NX
  scans give 6.8–8.5); sh in mm, so 20 µm = 0.020; recognised by the
  command alone (first motor sh). Other beamline motor names for the
  sample height, if any, are not known.

- Burn tests: the position's change shown as % of the FWHM (the owner
  leaves its judgment to the user; it does not set the limit by default).

- Known-ratio Monc/Monp tolerance 3 %.
- Covariance export (2026-11-22): the window option off by default and
  writing sidecars beside the legacy files; Σ of the legacy patch from
  recomputed counting errors; known-ratio joins without foil
  correlations; Σ of the joint patch from the counting spread of its
  factors; stitched output averaged at coinciding Q_z
  (`reports/downstream_covariance.md` §8).
- Per-photon: gas at the table's conditions; one factor per scan from the
  median rate (dark term ≲ 0.05 %).
- GID: minimum 2 frames per bin; β grid step = the largest row step.
- GID overlap pixels: ΣN/ΣW rather than IDL's error weights.
- P39 fix: raised arm above β0 = 1° keeps IDL's high edge (streak).
