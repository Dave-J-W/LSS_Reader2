# Absorber-step deliverables for LSS_Reader2 hand-off 02 (2026-11-18)

Answers to "measure the absorber steps by patching reflectivity scans". Generated by `tools/absorber_steps.py`
(`python -I tools/absorber_steps.py .`) from the SPEC data files in `c51_surface/`; do not edit by hand.

| File | What it is |
|---|---|
| [REPORT.md](REPORT.md) | Method and changes to the hand-off (no `proi`; slits per the owner), join summary, per-day fits, level shifts by run, day-to-day tables, systematics, answers to questions 1 to 4, and the calibration-or-patching verdict. |
| [HANDOFF.md](HANDOFF.md) | Short hand-off to LSS_Reader2: where the answers are, the results, the open items. |
| [REVIEW_03.md](REVIEW_03.md) | Answer to hand-off 03 (LSS_Reader2's review): the foil fit reproduced (and by half-year, at 1 % tolerance), the slit classifier fixed, which scan is off at the anomalous joins (scan a's Monc at the narrow S1 gap; not a preamp offset), the blades before and after, Monc/Monp along scan b, and which of their numbers were reproduced. Made by `tools/absorber_review.py`. |
| `figdata/` | The data behind the five review figures (`joins_review.csv`, `per_run_residual.csv`, `foils.csv`, `recurring.csv`). |
| `joins.csv` | Every join with the hand-off's columns plus slits changed (from `#P`), Monc/Monp across the join, gains, time between the overlap points, peak ROI rate of scan b, and exclusions. |

File and run ids are anonymous (the mapping `c51_surface/monitor_noise_ids.tsv` stays local). Figures (PNG, not
committed): `figures/absorber_steps_overview.png`, `absorber_steps_systematics.png` and `absorber_foils.png`, and the review's `figures/absorber_review_1.png` to `_5.png`. The hand-off's own
script (`02-absorber_steps.py`, kept in Downloads, not imported) reproduces its worked example; this tool matches it.
